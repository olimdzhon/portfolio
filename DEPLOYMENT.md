## 🚀 Как обновить сайт:

1. Внесите изменения в файлы (index.html, styles.css, script.js)
2. Закоммитьте изменения:
   ```bash
   git add .
   git commit -m "Описание изменений"
   ```
3. Запушьте в GitHub:
   ```bash
   git push origin main
   ```
4. GitHub Actions автоматически задеплоит изменения
5. Сайт обновится через 1-2 минуты
