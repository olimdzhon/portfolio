# Портфолио Olimjon Sadykov

Современное портфолио-сайт для Software Developer с акцентом на мобильную разработку и blockchain технологии.

## 🚀 Особенности

- **Современный дизайн**: Темная тема с градиентами и плавными анимациями
- **Полностью адаптивный**: Отлично выглядит на всех устройствах
- **Интерактивные элементы**: Анимации при скролле, hover-эффекты
- **Оптимизированная производительность**: Быстрая загрузка и плавная работа
- **SEO-оптимизация**: Правильная структура и мета-теги

## 📁 Структура проекта

```
portfolio-website/
├── index.html          # Основная HTML-страница
├── styles.css          # Все стили
├── script.js           # JavaScript функциональность
└── README.md           # Документация
```

## 🎯 Основные возможности

### Навигация
- Фиксированная навигационная панель
- Плавная прокрутка к секциям
- Мобильное меню-гамбургер
- Активное состояние текущей секции

### Анимации
- Fade-in эффекты при скролле
- Анимация прогресс-баров навыков
- Hover-эффекты на карточках проектов
- Печатающийся эффект для подзаголовка
- Parallax эффект для hero-секции

### Интерактивность
- Копирование email в буфер обмена
- Динамическое изменение фона навигации
- Клавиатурная навигация (ESC для закрытия меню)
- Плавные переходы между секциями

## 🚀 Запуск

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер:

```bash
# С помощью Python
python -m http.server 8000

# С помощью Node.js (http-server)
npx http-server

# С помощью PHP
php -S localhost:8000
```

3. Откройте браузер: `http://localhost:8000`

## 🎨 Кастомизация

### Цветовая схема

Измените CSS переменные в `styles.css`:

```css
:root {
    --primary-color: #6366f1;      /* Основной цвет */
    --secondary-color: #8b5cf6;    /* Вторичный цвет */
    --accent-color: #ec4899;       /* Акцентный цвет */
    --dark-bg: #0f172a;            /* Темный фон */
    --darker-bg: #020617;          /* Более темный фон */
}
```

### Контент

Отредактируйте `index.html` для изменения:
- Личной информации
- Списка навыков
- Проектов
- Контактных данных
